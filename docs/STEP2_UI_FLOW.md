# STEP 2 UI・画面遷移

## 目的

サンプルUI1を基に、先生が迷わず使えるシンプルな校務AI画面を作る。

## 今回の到達点

- ホーム画面を学校背景＋大きな10機能カードへ変更
- 画面上部のタイトルを「校務AIアシスト」に統一
- 説明過多になっていた文章や注意文をホーム画面から削除
- 10機能すべてをクリック可能に変更
- 機能選択後、入力画面へ移動
- 「AIで作成する」で完成画面へ移動
- 完成画面にコピー・編集・簡単調整を配置
- 現段階ではAI未接続のため仮出力を表示

## 基本動線

```text
ホーム
  ↓ 1クリック目：機能を選択
入力画面
  ↓ 内容を入力
「AIで作成する」
  ↓ 2クリック目
完成画面
```

## ホーム画面

表示する10機能：

1. 校務文書作成
2. 文書チェック
3. 保護者連絡文
4. 学年通信支援
5. 会議メモ整理
6. 授業アイデア
7. 研修・研究支援
8. メール作成
9. 言い換え
10. 校内FAQ

## 入力画面

機能ごとに以下を切り替える。

- アイコン
- 機能名
- 説明
- 入力欄ラベル
- 入力例
- 文章の長さ
- 文章の雰囲気

文書チェック、会議メモ整理、校内FAQでは、現段階で不要な長さ・雰囲気の設定を非表示にしている。

## 完成画面

- 仮生成結果
- コピー
- 編集に戻る
- もう少し短く
- もっとやわらかく
- より正式にする
- 別の表現で作る
- ホームへ戻る

## 学校背景

今回の背景は、特定の写真を転載せず、校舎・樹木・空をイメージしたオリジナルのCSS/SVG表現としている。
