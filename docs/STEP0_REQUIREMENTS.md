# STEP 0 — 基本仕様・要件定義

## 1. アプリ名称

**高砂市立高砂中学校 校務AIアシスト**

副題（仮）: **先生の「書く・まとめる・考える」を、もっと簡単に。**

初期公開時は「試作版 / 校務利用」を明示します。

## 2. 開発目的

中学校教員が日常的に行う文章作成・校正・整理・授業準備を、生成AIを意識せず短い操作で支援するWebアプリを作ります。

設計原則は次の4点です。

1. **迷わせない** — ホーム画面から目的を直接選べる。
2. **2クリックで生成** — 「機能を選ぶ」→「AIで作成する」を基本動線にする。
3. **大きく見やすい** — 大きな文字、大きなボタン、色で機能を識別する。
4. **AIを裏方にする** — ユーザーが複雑なプロンプトを書かなくても、機能別の専用プロンプトが自動で働く。

## 3. 学校固有の反映方針

公式サイトに掲載されている学校名、生成AIパイロット校としての取組、校訓「自主・友愛・創造」を踏まえて、学校向けの落ち着きと先進性を両立したUIにします。

初期版では、校章・校舎写真・生徒写真などの権利物は埋め込みません。学校側から利用可能な素材が提供された場合のみ追加します。

## 4. 最終搭載する10機能

| No. | 機能 | 主な入力 | AIが返すもの |
|---:|---|---|---|
| 1 | 📝 校務文書作成 | 要点・日付・対象 | 案内文、依頼文、通知文 |
| 2 | ✅ 文書チェック | 作成済み文章 | 誤字、表記揺れ、修正文 |
| 3 | 📢 保護者連絡文 | 状況・連絡事項 | 丁寧で簡潔な連絡文 |
| 4 | 🏫 学年通信支援 | 行事・話題 | 学年通信の文章案 |
| 5 | 📋 会議メモ整理 | 箇条書きメモ | 決定事項、課題、担当 |
| 6 | 📚 授業アイデア | 教科・単元・時間 | 授業展開、発問案 |
| 7 | 🎓 研修・研究支援 | テーマ・課題 | 協議事項、研究案 |
| 8 | ✉️ メール作成 | 相手・目的・要点 | 校務向けメール案 |
| 9 | 🔄 言い換え | 元文章 | 丁寧、簡潔、保護者向け等 |
| 10 | ❓ 校内FAQ | 校内ルールに関する質問 | FAQ・根拠に基づく回答 |

※ 校内FAQのみ、後工程でRAG（検索拡張生成）方式を導入します。

## 5. UI基本仕様

### ホーム画面（UI1）

- 10機能を大きなカラフルタイルで表示。
- PCでは3〜4列、タブレットでは2〜3列、スマホでは2列を基本とする。
- タイル内は「アイコン → 機能名 → 一言説明」の順。
- 文字は小さくしすぎず、教職員が初見で機能を判断できることを優先。

### 作成画面（UI2）

- 機能名と目的を大きく表示。
- 入力欄は1つを基本とし、必要な場合のみ「文章の長さ」「雰囲気」等の簡単な選択肢を付ける。
- 最下部に大きな **「AIで作成する」** ボタンを1つ置く。

### 完成画面

- 生成結果を読みやすい白背景カードで表示。
- 「コピー」を最重要ボタンとする。
- 追加操作として「短くする」「やわらかくする」「より正式に」「もう一度作る」を用意する。

## 6. 操作目標

基本操作は次の2クリックです。

```text
1クリック目：使いたい機能を選択
        ↓
必要事項を入力
        ↓
2クリック目：「AIで作成する」
        ↓
完成
```

入力内容の微調整や完成後の再編集は追加操作とします。

## 7. 技術構成

### フロントエンド

- GitHub Pages
- HTML / CSS / JavaScript
- 外部フレームワークは初期版では使わず、軽量・高速・保守しやすい構成

### API中継

- Cloudflare Workers
- ブラウザからAI APIへ直接アクセスしない
- APIキーはCloudflare Secretsで管理

### AI

1. **Cerebras** — 主AI
2. **Groq** — 予備AI 1
3. **Gemini** — 予備AI 2

### フェイルオーバー

主AIがタイムアウト、429、5xx、ネットワーク障害等の場合のみ次のAIへ切り替える設計にします。

```text
Cerebras
  ↓ 失敗
Groq
  ↓ 失敗
Gemini
```

入力不備や文字数超過など、ユーザー側で修正すべきエラーはAIを切り替えません。

## 8. 安全・個人情報方針

初期版では次の情報を入力しない運用とします。

- 生徒・保護者・教職員の氏名
- 住所、電話番号、メールアドレス
- 成績、評価、出欠等の個人データ
- 健康情報、家庭状況などのセンシティブ情報
- 個人を特定できる自由記述

UI上に常時、次の注意文を表示します。

> 個人を特定できる情報や、成績・健康情報などの機微な情報は入力しないでください。

入力本文は原則としてアプリ側に保存しません。

## 9. STEP 0で固定する事項

- アプリ名
- 10機能
- 2クリック動線
- UI1 → UI2 → 完成画面の基本構造
- GitHub Pages + Cloudflare Workers

- APIキーをフロントへ置かない
- 初期版では個人情報を扱わない
